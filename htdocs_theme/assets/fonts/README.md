# Local Typography Assets

Per Module 13 Design System requirements, fonts must be loaded locally to avoid external CDNs and comply with privacy/performance standards.

## Required Font Files

Please place the following WOFF2 files in this directory:

### Noto Serif (Display Serif)
- 
oto-serif-v22-latin-regular.woff2 (400)
- 
oto-serif-v22-latin-700.woff2 (700)

### Inter (UI Sans-Serif)
- inter-v12-latin-regular.woff2 (400)
- inter-v12-latin-500.woff2 (500)
- inter-v12-latin-600.woff2 (600)

These fonts have already been wired into the 	heme.json fontFace declarations. Once the files are present, they will automatically be loaded by WordPress.
