# Prakash Marg - Enterprise Architecture v1.0

This repository contains the completed Sprint modules for Prakash Marg:
- **Theme Foundation**: wp-content/themes/prakash-marg
- **Core Platform & Entity Engine**: wp-content/mu-plugins/prakash-marg-core

## Features Included:
1. Universal Entity Engine (Entity Registry, Storage Manager, Repositories).
2. Temple Entity Implementation (Backend Configuration & Mapping).
3. Presentation Layer: Dynamic Gutenberg Blocks for Temple and Homepage.
4. FSE Templates: single-pm_temple.html, ront-page.html.

## Deployment:
Copy the wp-content folder into your root WordPress installation to merge the themes and mu-plugins directories.
